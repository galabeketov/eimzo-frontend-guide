# 6. ID-karta va qurilmalar

<!-- TODO: to'ldirish kerak -->

Reja:
- ID-karta (`idcard`): `list_readers`, o'quvchi qurilma bor-yo'qligi, PIN oynasi, minimal versiya 4.12.
- BAIK (`baikey`) va CKC (`ckc`): `list_tokens` / `list_ckc`, minimal versiya 4.86.
- Qurilmadagi sertifikat ro'yxatda ko'rinmaydi — faqat imzo ichida. UI da faqat qurilma turini ko'rsatish mumkin.
- Driver yo'q bo'lsa plugin rad etadi — boshqa qurilmalarni yashirmang.
- Mobil oqim (E-IMZO mobil ilova, QR): alohida bo'lim.
