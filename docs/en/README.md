# E-IMZO frontend integration guide

Translation in progress. The primary version is [in Uzbek](../../README.md).

E-IMZO is Uzbekistan's digital signature desktop client. Web pages talk to it over a WebSocket to 127.0.0.1. This guide documents that protocol framework-independently.

Help with translation is welcome: take a file from `docs/uz/`, translate it under the same name into `docs/en/`.
